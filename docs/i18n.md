# i18n — NeuroPharm v1

NeuroPharm est livré en **français** (par défaut) et **anglais**. La langue est choisie côté client et persistée dans `localStorage` via `I18nProvider`.

## Fichiers

```
src/lib/i18n/
  index.ts   # exports { fr, en, Locale, localeNames, Translations }
  fr.ts      # dictionnaire français
  en.ts      # dictionnaire anglais
```

## API

Dans n'importe quel composant client :

```tsx
'use client'
import { useI18n } from '@/components/I18nProvider'

export default function Example() {
  const { t, locale, setLocale, locales } = useI18n()
  return <h1>{t('dashboard.title')}</h1>
}
```

- `t(key)` accepte une clé pointée (`section.key`) et renvoie la chaîne dans la locale courante.
- `setLocale('fr' | 'en')` change la locale et persiste dans `localStorage` (`neuropharm-locale`).
- `locales` est `['fr', 'en']`, `localeNames` mappe vers les libellés affichés.

## Typage — important

`Translations` est volontairement défini comme :

```ts
export type Translations = Record<string, Record<string, string>>
```

> ❌ **Ne pas** redéfinir `Translations` comme `typeof fr` ou avec `as const`. Cela transforme les valeurs en types literals (`'Enregistrer'`, `'Tableau de bord'`…), et `en.ts` ne pourra plus être assigné à `Translations` (`Type '"Save"' is not assignable to type '"Enregistrer"'`). Cet incident a déjà été corrigé une fois.

## Ajouter une clé

1. Ajouter la clé dans `fr.ts` **et** `en.ts`, dans la même section.
2. Si la section est nouvelle, l'ajouter aux deux fichiers (sections sont des objets de premier niveau).
3. Utiliser `t('section.key')` dans le composant.

Exemple :

```ts
// src/lib/i18n/fr.ts
export const fr = {
  // …
  superadmin: {
    title: 'Tableau de bord SaaS',
    pharmacies: 'Pharmacies',
    addPayment: 'Enregistrer un paiement',
  },
}
```

```ts
// src/lib/i18n/en.ts
export const en = {
  // …
  superadmin: {
    title: 'SaaS dashboard',
    pharmacies: 'Pharmacies',
    addPayment: 'Record a payment',
  },
}
```

## Conventions

- Les clés sont en `camelCase`.
- Les sections regroupent par domaine fonctionnel, jamais par page individuelle (sinon explosion du nombre de clés).
- Une chaîne n'est jamais en dur dans un composant client : si elle est destinée à l'utilisateur, elle passe par `t()`.
- Les formats numériques / dates utilisent `Intl.NumberFormat('fr-FR', { style: 'currency', currency: 'XOF' })` et `Intl.DateTimeFormat(locale, …)` — pas de chaînes traduites pour ça.
- Les chaînes côté **server** (réponses API, erreurs Prisma) sont en français côté code et traduites côté client si besoin.
